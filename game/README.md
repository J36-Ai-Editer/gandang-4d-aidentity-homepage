# 현재 화면: 3D 스타일 검토 시안

`index.html`은 Three.js의 실제 3D 오브젝트로 만든 한옥·연못·정자·나무와 SD 사람을 표시한다. 클릭 경로 이동, 방향키/WASD/화면 버튼 이동, 시점 30도 회전, 확대·축소·기본 시점을 지원한다. 건물·연못 충돌을 적용한다. 시각 방향 검토 단계라 새 3D 화면의 퀘스트·꾸미기·저장은 아직 연결하지 않았다. 기존 2D 화면은 `village-2d.html`에 그대로 보존했다. 생성 콘셉트 이미지와 같은 완성 아트 품질을 주장하지 않는다. 기획서와 외부 기획 입력은 보류했다.

# 간당마을 — 화면 구도 기반 플레이 시제품

승인된 한국 마을 구도를 전체 화면 배경으로 사용하고, 독립된 캐릭터·이동 영역·장식·대화·메뉴를 Canvas와 HTML로 구현했다. 첫 화면은 `index.html` / `src/scene.ts`다. 이전 격자형 Excalibur 시제품은 `legacy.html`에 보관했다.

## 실행

저장소 루트에서 `powershell -ExecutionPolicy Bypass -File scripts/run_isometric_game.ps1` 실행 후 http://127.0.0.1:5178/ 에 접속한다. Node.js 22.12 이상이 필요하다. 종료는 실행 창에서 Ctrl+C.

- 길 클릭: 경로 탐색 이동. 방향키·WASD·화면 이동 버튼도 지원한다.
- 마을지기 클릭: 가까이 이동 후 대화. 가까이에서 E 또는 대화 버튼도 가능하다.
- 첫 의뢰: 대화 → 꾸미기에서 꽃 배치 → 돌아와 대화.
- 꾸미기: 꽃·등불 선택 → 광장 빈자리 클릭 → 확인. 회수도 가능하다.
- 가방: 배치 현황. 지도: 현재 위치. 우측 상단: 조작 안내.

위치·장식(최대 40개)·의뢰 진행은 기기 localStorage의 `gandang-village-scene-v2`에 저장한다. 손상된 값과 잘못된 좌표는 검증한다. 계정·건강정보·실제 보상·결제와 연결하지 않았다.

## 검증

`npm run typecheck`, `npm run lint`, `npm test`, `npm run build`.
브라우저에서 클릭 이동, 주민 대화, 꽃 배치, 의뢰 완료, 새로고침 저장 복원 및 320px 지도 메뉴를 확인했다.

## 구현 범위

풍경은 N.BeAI에서 생성한 고정 배경 그림이다. 지붕·나무·연못은 독립된 3D 오브젝트가 아니며 내부 진입이나 모든 풍경의 재배치는 지원하지 않는다. 산책은 흙길과 광장에 한정한다. 배경에 남아 있는 작은 인물은 풍경의 일부이며 대화 대상이 아니다. 움직이는 플레이어와 말풍선이 있는 마을지기, 새로 놓은 꽃·등불은 별도 렌더링하며 발 위치 순으로 정렬한다.

상용 게임의 원본 그래픽을 사용하지 않았다. 생성 자산은 최종 IP·권리 검토 전 시제품이며, 엔진의 라이선스가 이미지에 자동 적용되지는 않는다. 기존 Excalibur 시제품의 의존성 고지는 해당 패키지를 따른다.

## 2026-11-24 무릉도원 확장

이후 최신 사용자 지시로 이동 경계를128×128로 확장하고, 굽이치는강·다리3개·언덕·꽃군락·산능선·폭포·운무를 추가했다. Three.js 실제3D 지형과 발 높이/경로가 연동된다. 음표버튼으로 기존BGM을 재생한다. 현재 구동환경은 독립Three.js이며 위의 과거2D 의뢰/배치저장 설명은 legacy 이력이다. 새3D에서 의뢰·꾸미기저장·계정연결이 구현된 것으로 해석하지 않는다. 타입·린트·13테스트·빌드 및 실제320/390px 프레임을 확인했다. 영상과동등한 모델·리깅 완성본은 아니며 최종 시각검토대기, 공개서버미배포. 상세 docs/20261124-expanded-village.md 및 docs/gandang4d-astra-next-prompt-20261124.txt 참고.
산사 탐방로는 중앙 다리를 건너 북쪽 복숭아 언덕에서 이어집니다. 불상 앞의 눈 아이콘으로 감상 시점을 전환하거나 종각 옆의 종 아이콘으로 범종을 울립니다. 남쪽 들길은 외곽을 순환합니다. 불상은 특정 사찰 유물을 복제하지 않은 창작 조형입니다.
폭포 동쪽 정자에서 물결 아이콘으로 계곡 소리를 켜거나 끕니다. 처마의 풍경 아래에서 종 아이콘을 누르면 풍경이 흔들리며 울립니다. 정자에서 멀어지면 물소리가 서서히 줄어듭니다.
갈대 습지는 동쪽 다리(동쪽 세 번째 다리)를 건너 북동쪽 길로 이어집니다. 여울·거북·학 가까이에서 행동 아이콘으로 상호작용합니다. 로컬에서 /?visit=wetland로 습지 입구로 바로 들어갈 수 있습니다.
Space로 점프, Shift를 누른 채 방향키로 달리기, 마을 벤치나 계곡 정자 벤치 가까이에서 멈추면 자동으로 앉고, 이동하면 다시 일어납니다. /?visit=rig는 관절 제작용 T 자세 미리보기입니다. 한옥과 주인공은 건물2·건물3·주인공 이미지를 보면서 Three.js 메시로 다시 모델링한 첫 시안입니다.
한옥 처마는 기와와 지붕 면에 같은 곡률을 적용하고, 측면 창호와 옹기를 추가했습니다. 주인공에는 눈과 입, 소매 끝동, 삿갓의 짜임을 추가했습니다. 로컬 브라우저에서 물·거북·학을 한 세션에서 발견하여 3/3을 확인했습니다.
습지 북쪽의 솔숲길에서 발자국이 시작됩니다. 발자국을 따라 사슴에게 인사하고, 능선 너머 소나무 밑 불로초를 관찰할 수 있습니다. 고개 동쪽 길은 습지로 돌아옵니다. 로컬 /?visit=forest에서 숲 입구를 바로 확인할 수 있습니다.
첫 화면의 사람 주민에게 다가가면 남녀형과 한복 색을 바꿀 수 있는 아이콘이 나타납니다. 두 외형은 같은 팔꿈치·무릎 관절과 동작을 사용합니다. 십이지신 주민은 각자 정해진 목적지까지 걷고 잠시 멈춘 뒤 돌아옵니다.
