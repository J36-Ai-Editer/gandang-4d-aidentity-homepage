목표: 실제 탐험 가능한 한국적 무릉도원. 2D처럼 정돈된 3D, 한옥·복숭아꽃·12지신 주민을 유지한다. 단순한 도형 수 증가가 아니라 지형과 물길, 가까운 풍경부터 먼 능선까지의 구도를 자연스럽게 교정한다.
현재 경계 ±64(128×128), 중앙 평지와 외곽 완만한 언덕 terrainHeight, 폭이 달라지는 S자 riverCenter/riverHalfWidth, 다리 x=-25/0/25, 불규칙 GROVE_TREES, 폭포(-48,-34), 국소 운무, 산능선, 추적카메라/전체 지도/음표 버튼 BGM이 있다. 이미 구현된 항목을 처음부터 재작성하지 말고 먼저 실제 구동 상태를 읽고 비교한다.

1. 동선과 지형
- 광장(0,3) 반경 12는 시야를 열어 둔다. 생활 골목·텃밭은 현재 한옥 주변, 북쪽 곡류는 다리 3개와 연결, 외곽은 꽃 군락과 언덕·폭포 산책로로 구성한다.
- 광장→다리0→북쪽 주거→다리±25→생활 골목→광장 및 외곽 언덕→폭포 전망→꽃 군락→귀환의 두 루프가 실제 이동 가능해야 한다. 길이 건물·나무·물·절벽을 관통하면 지형과 배치를 수정한다.
- 높이 함수와 실제 지형 메시·길·발 높이·다리 높이를 같은 기준으로 맞춘다. 물가에서 가상의 다리 높이가 적용되지 않게 한다. 급경사·암벽은 막고 완만한 길로 우회한다.

2. 자연스러운 배치와 아트
- 원형 숲 울타리, 등간격 나무·복제 건물 줄세우기를 피한다. 밀집 군락과 성긴 가장자리, 빈 들을 번갈아 두고 크기·회전·간격에 절제된 편차를 준다.
- 근경은 낮은 풀·바위·꽃, 중경은 한옥·초가·장터·다리·정자, 원경은 완충 숲 뒤 능선·폭포·운무로 분리한다. 광장과 플레이어를 가리는 큰 수목을 낮추거나 옮긴다.
- 엔비아이 팔레트: 꽃 #F7B7C7 / #E97A9C, 바위 #8A8177 / #5B5F66, 운무 #EDE9E3 / #C9D6E2. 진핑크는 작은 포인트, 안개는 외곽·폭포에만 얇게. 따뜻한 단일 시간대의 부드러운 그림자와 재질을 유지한다.
- 랜드마크: 꽃 언덕의 고목, 물가의 아치 다리·정자, 바위 사이 폭포. 경관을 가리는 안개·과도한 후처리는 줄인다. 사각 지면 끝·카메라 근평면 절단·튀는 수면과 붕 뜬 소품을 실제 캡처로 찾아 교정한다.

3. 조작·성능·검수
- 게임은 아이콘 중심 UI와 aria-label을 유지한다. 이동/인사/회전/줌/원복/전체지도/BGM이 작동해야 한다. BGM은 기존 gandang-theme.mp3를 사용하고 자동재생 차단을 우회하지 않는다.
- 320×740 및 390×844 실제 iframe에서 조작 버튼이 가로·세로로 넘치거나 서로 가리지 않는지 확인한다. 가짜 viewport 수치만 보고 통과시키지 않는다.
- 숲/소품의 고정 지형 묶기 또는 인스턴싱과 거리별 표시를 검토하되 동작하는 팔·다리·꽃잎·물결을 고정 지형으로 합치지 않는다. 전체 지도와 산책 시점의 실제 렌더 비용도 확인한다.
- 타입검사/린트/테스트/빌드, 장애물·곡류·다리·언덕 경로, 카메라 추적, 클릭/키/터치 이동, BGM 실재생을 확인하고 실패를 수정한다. 비교 가능한 광장/외곽/모바일 캡처를 남긴다.

4. 경계와 제출
- Tripo 또는 새 유료 API를 사용하지 않는다. 브랜딧·엔비아이는 브랜드/아트 협업 수단이며 31개 PNG가 GLB로 변환됐다고 표현하지 않는다. 건강 원자료·계정·미션·보상·가족 기능은 추가하지 않는다.
- 기업 메인의 기존 3분할을 유지한다. 매니패스트/이그나이트 기획 입력은 사용자 지시 없이 수정하지 않는다. Ign8t 작업 문맥과 최신 사용자 결정을 읽고 실제 완료 수준에 맞게 보드를 갱신한다.
- 원본·ver.1/ver.2 백업과 사용자 변경을 보존한다. 비밀정보·개인정보를 커밋하지 않는다. main/develop 직접 push 금지, 기존 PR에 후속 커밋. 원본·결과물·프롬프트를 공동자료실과 저장소에 함께 남긴다. 사용자 최종 확인 없이 공개 서버에 배포하지 않는다.
- 영상과 동등한 완성도는 실제 비교 후 판단한다. 아직 부족한 모델/리깅/성능은 구체적으로 남기고 완료로 과장하지 않는다.
