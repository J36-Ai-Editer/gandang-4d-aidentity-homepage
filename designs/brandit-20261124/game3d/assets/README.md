# 마을 그래픽

`korean-village-atlas.png`는 이 프로젝트를 위해 2026-11-23 생성한 오리지널 이미지다. 2×2 구역: 한옥, 소나무, 정자, 벚나무. ZEP 또는 외부 게임 자산을 복제하지 않았다. 런타임에서 각 구역을 개별 월드 오브젝트로 표시하며, 발 위치 정렬과 충돌은 별도 게임 로직이 담당한다.

기존 Excalibur 엔진의 BSD-2-Clause 고지는 해당 패키지를 따른다. 엔진 라이선스와 생성 이미지의 권리를 혼동하지 않는다. 생성 그래픽은 최종 IP 제작·권리 검토 전 시제품 자산이다.
