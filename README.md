# 간당간당4D 및 기업 메인 홈페이지

Aidentity 기업 홈페이지와 한국 마을 힐링 게임 환경의 공개 소스입니다.

- 기업 홈페이지: https://www.aidentity.kr/
- 게임 체험: https://www.aidentity.kr/game3d/
- 현재 게임: 간당간당4D ver.2 환경 1차

## 구성

| 경로 | 내용 |
| --- | --- |
| `site/` | 현재 공개된 기업 메인·철학·팀 페이지, 로고·BGM·사진 및 게임 배포본 |
| `game/` | Three.js + TypeScript + Vite 게임 소스, 테스트 및 이전 2D 실험 이력 |
| `backups/gandang3d-ver1-20261124.zip` | ver.2 작업 전 간당간당3D ver.1 소스 백업 |

## 게임 실행

```sh
cd game
npm ci
npm run dev
```

`npm run typecheck`, `npm run lint`, `npm test`, `npm run build`로 검증합니다.
기업 홈페이지는 저장소 루트에서 `python -m http.server 5180 --directory site` 후 열 수 있습니다.

## ver.2 환경 1차

한옥·돌담·벚나무·연못을 유지하며 자체 형태 모델로 십이지신 주민 12종, 주변 산책, 가까운 주민 인사, 텃밭·장터, 꽃잎·물결 움직임을 추가했습니다. 이동은 바닥 클릭·방향키·화면 버튼, 카메라는 회전·확대/축소를 지원합니다. 화면은 아이콘 중심입니다.

환경 프로토타입이며 완성 게임이 아닙니다. 새 3D에서 퀘스트·꾸미기 저장·건강 API·운영 보상·멀티는 미구현입니다. 기존 2D 실험의 저장 테스트 통과를 3D 기능 완성으로 해석하지 않습니다. 건강 예측은 진단·처방이 아닌 위험 선별·건강교육을 위한 별도 서비스입니다.

## 백업 복구

ver.1 ZIP에는 `src/`, 진입 HTML, 패키지 파일과 릴리스 기록이 있습니다. 실행에 필요한 변하지 않은 `game/tsconfig.json`, `game/vite.config.ts`, `game/eslint.config.js`와 조합해 별도 폴더에서 설치·실행할 수 있습니다. 기존 실험용 2D 에셋은 `game/public/`에 있습니다.

## 브랜드 및 자료

Aidentity·간당간당 로고와 팀 사진·BGM은 기존 프로젝트에서 사용자가 제공한 자료입니다. 십이지신 주민과 현재 3D 환경은 자체 코드 기반 형태 모델입니다. 공개 저장소라는 이유만으로 브랜드·인물 사진·음원·이미지의 제3자 재사용 권한을 부여하지 않습니다. 외부 오픈소스의 라이선스는 개별 확인 후 적용하며 이번 변경에는 외부 게임 코드를 복사하지 않았습니다.

API 키·비밀번호·의료 원자료·학습 모델·비공개 문서는 포함하지 않습니다. 개발 변경은 `codex/*` 브랜치와 Issue/PR로 진행합니다.
